## GitHub 基础概念

- 仓库（Repository）：存放项目文件和修改记录的地方。
- 分支（Branch）：一条独立的工作路线；目前我使用的是 `main` 分支。
- 提交（Commit）：为一次修改创建一条带说明的保存记录。
## 第 3 天：分支

分支可以让我在不影响 `main` 的情况下独立修改内容。
## 第 4 天：Issue
